Things that broke, and how I fixed them

Each of these started as a real problem on an enterprise agent platform used by many companies at once.

Performance

Reopening an old conversation took far too long

Cause
Loading a past chat rebuilt the whole agent and its tools just to read the message history.
Fix
Read the agent's saved state straight from storage, and repaired a background job that had been failing silently.
~30xfaster to reopen a past conversation
Client delivery

An IT service desk agent inside Microsoft Teams

Built
A Copilot Studio agent for a large consumer-goods company, connected to their ticketing system over MCP for tickets, notifications and status updates.
Scale
Available to 50,000+ employees, with 50+ Power Automate workflows behind it.
75%less manual L1 ticket handling
Security

Letting agents read the live web without opening the internal network

Built
A web capability where agents search the whole web or only chosen sites.
Guard
Blocks internal and cloud-metadata addresses, re-checks every redirect, and stops look-alike domains from slipping past the allow-list.
Every hopre-checked, so a redirect can't bounce an agent into the internal network
RAG quality

Teaching agents to say "I don't know"

Cause
Agents with an empty knowledge base could invent answers and citations.
Fix
A clear no-data signal from retrieval, and citations that point to the exact source record.
No datais now an allowed answer, and every citation points to a real record
Observability

Finding messages nobody knew were lost

Cause
Messages filtered out before an agent ran left no trace at all.
Fix
One outcome record per message across Mail, Teams, Webhook and A2A, with a query API and skip-rate alerts.
4channels now tracked end to end
Reliability

Giving each agent only the tools it needs

Cause
Agents were handed far more tools than intended, which confused them and caused failures.
Fix
A per-agent tool allow-list, a data migration to backfill it, and strict checks at runtime.
Least privilegefor every agent, plus new MCP servers for cloud and IT-service tools
